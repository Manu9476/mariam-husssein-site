# Basic SEO Checklist

## Before Launch

- confirm `NEXT_PUBLIC_SITE_URL` matches the final public domain
- confirm `NEXT_PUBLIC_WORDPRESS_URL` points to the correct WordPress install
- add a unique SEO title and SEO description in the `Headless SEO` box for important pages and posts
- set an Open Graph image URL for major pages and cornerstone posts
- upload meaningful featured images for posts, pages, and resources
- check that `sitemap.xml` and `robots.txt` are live on the frontend domain
- make sure page slugs are clean and human-readable
- verify site title and tagline in WordPress Site Identity

## Content Hygiene

- keep post titles clear and editorial rather than keyword-stuffed
- write strong excerpts because they are used as summaries across the site
- use categories intentionally instead of creating too many overlapping ones
- keep About, Contact, Privacy Policy, and Terms published at all times

## Recommended Next Improvements

- add on-demand revalidation from WordPress to Vercel
- add structured data for articles, organization, and testimonials
- connect analytics and search console
- add preview mode for drafts
